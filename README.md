Высокопроизводительная автоматизированная система полного цикла для быстрого парсинга товаров, их интеллектуальной публикации и управления объявлениями на украинском маркетплейсе **Shafa.ua** с современным графическим интерфейсом на CustomTkinter.

---

## 🚀 Ключевые технические решения и возможности

* ⚡ **Сверхбыстрый парсинг (Apollo State HTTP Engine)**:
  * Парсер извлекает 100% структурированных данных товара (полное название, неограниченное описание, цены, состояние, бренд, категории `RootCatalog`, цвета, размеры и оригиналы фото) напрямую из состояния Apollo через быстрый HTTP-запрос (~0.5–1 сек на товар).
  * Не требует запуска отдельного окна браузера для парсинга, что исключает нагрузку на CPU и память.

* 🖥️ **Архитектура единого браузера (Single Browser Instance)**:
  * Для публикации используется ровно один постоянный экземпляр Chrome с сохранением профиля сессии.
  * Первый товар заполняется в текущей вкладке, а каждый последующий — в новой вкладке для удобной проверки.

* 🛡️ **Система защиты сессии (Login Guard)**:
  * Автоматическая проверка авторизации перед запуском конвейера.
  * Если сессия истекла, программа ставит конвейер на паузу и открывает интерактивное диалоговое окно, ожидая входа прямо в браузере, после чего бесшовно продолжает работу.

* 📋 **Полный отказ от буфера обмена (React Native Dispatcher)**:
  * Ввод текстов и описаний переведен на вызов нативного сеттера прототипа браузера с генерацией синтетических событий React (`dispatchEvent('input')`).
  * Системный буфер обмена Windows **100% свободен** — вы можете копировать текст, код или играть во время работы бота без риска перезаписи буфера.

* 🖼️ **Smart Upload Guard и RGB-нормализация фото**:
  * Динамический мониторинг состояния загрузки через JavaScript: бот отслеживает исчезновение спиннеров и полную отрисовку картинок, адаптируясь под скорость интернета.
  * Принудительная конвертация изображений в профиль `RGB` перед сохранением baseline JPEG исключает появление «битых миниатюр» на сервере Шафы.
  * Точный естественный порядок фото (главное фото всегда на 1-м слоте).

* 🖥️ **Нативная поддержка мультимониторов (2-й экран)**:
  * Встроенное определение геометрии экранов через Windows API (`EnumDisplayMonitors`).
  * Возможность автоматически открывать и разворачивать Chrome на дополнительном (втором) мониторе.

* 🫥 **Скрытый режим работы с авто-показом в финале (Hidden & Auto-Reveal)**:
  * Chrome работает за пределами видимого экрана (`Off-Screen`), что отключает нагрузку на GPU.
  * По завершении заполнения всех товаров браузер мгновенно материализуется на выбранном мониторе и издает звуковой сигнал уведомления.

## 🛠️ Стек технологий

* **Язык:** Python 3.11+
* **Web Automation:** Selenium WebDriver
* **GUI Library:** CustomTkinter
* **HTTP / Data Extraction:** `requests`, `json`, `re` (Apollo State parser)
* **Image Processing:** Pillow (PIL)
* **Драйверы:** `webdriver-manager`
* **Windows API:** `ctypes.windll.user32`, `winsound`

## 📂 Структура проекта

```text
shafa-parser/
├── src/
│   ├── scraper/         # Быстрый Apollo HTTP-парсер с браузерным fallback
│   ├── publisher/       # Логика публикации, Smart Upload Guard, React Dispatcher
│   ├── models.py        # Строгая типизация данных (dataclass Product)
│   ├── config.py        # Конфигурация путей, папок и профиля Chrome
│   └── utils/           # Модули: display_utils, image_utils, logger, state_manager
├── main.py              # Главное окно GUI (CustomTkinter) и контроллер потоков
├── requirements.txt     # Актуальные зависимости проекта
└── README.md            # Документация проекта
```

## ⚙️ Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/DanilTet/shafa-parser.git
cd shafa-parser
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите приложение:
```bash
python main.py
```
