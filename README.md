Высокопроизводительная автоматизированная система полного цикла для быстрого парсинга товаров, интеллектуальной публикации, массовой миграции объявлений между аккаунтами и синхронизации каталогов на украинском маркетплейсе **Shafa.ua** с современным графическим интерфейсом на CustomTkinter.

---

## 🚀 Ключевые технические решения и возможности

### 🔄 1. Движок синхронизации и миграции профилей (Multi-Profile Sync Engine)
* **Мульти-профильная изоляция**:
  * Каждый продавец-источник получает изолированную базу состояния в `data/sync_profiles/{username}.json`.
  * Переключение между ранее отсканированными аккаунтами в один клик.
* **Сверхбыстрый сбор каталога (JS DOM-инжекция)**:
  * Прямая инжекция скриптов в DOM-дерево собирает 20+ товаров в секунду прямо в фоновом режиме.
* **Интеллектуальная автосверка (Reconciliation & Duplicate Guard)**:
  * Функция `Сверить с моим аккаунтом` сканирует ваш личный кабинет (`/my/clothes`), сопоставляет уникальные URL-слаги и заголовки и автоматически помечает уже выставленные вещи как `published`.
  * **Защита от дублей**: Если у исходного продавца товар был опубликован несколько раз (дубликаты), бот автоматически распознает и пропускает все копии.
* **Мягкая остановка (Graceful Stop)**:
  * При остановке бот доводит текущий товар до конца, фиксирует статус на SSD и аккуратно завершает конвейер. Ни один товар не теряется и не выставляется повторно.
* **Порционный перенос**:
  * Возможность переносить объявления порциями (`Все оставшиеся`, `10 товаров`, `20 товаров`, `50 товаров`).

---

### 📋 2. Поштучный парсер и автоматизация публикации (Single URL Pipeline)
* ⚡ **Сверхбыстрый Apollo HTTP-парсер**:
  * Извлекает 100% структурированных данных товара (полное название, описание, цены, состояние, бренд, категории `RootCatalog`, цвета, размеры и оригиналы фото) напрямую из состояния Apollo через HTTP-запрос (~0.5–1 сек на товар).
* 🖥️ **Архитектура единого браузера (Single Browser Instance)**:
  * Ровно один постоянный экземпляр Chrome с сохранением профиля сессии.
* 🛡️ **Система защиты сессии (Login Guard)**:
  * Автоматическая проверка авторизации и интерактивный диалог при истечении сессии.
* 📋 **Полный отказ от буфера обмена (React Native Dispatcher)**:
  * Ввод текстов через прямой вызов нативного сеттера прототипа с синтетическими событиями React (`dispatchEvent('input')`). Буфер обмена Windows **100% свободен**.
* 🖼️ **Smart Upload Guard и RGB-нормализация фото**:
  * Динамический мониторинг исчезновения спиннеров и загрузки картинок. Принудительная конвертация в RGB baseline JPEG исключает битые миниатюры.
* 🖥️ **Нативная поддержка мультимониторов (2-й экран)**:
  * Автоматическое открытие и разворачивание Chrome на дополнительном экране через Windows API (`EnumDisplayMonitors`).
* 🫥 **Скрытый режим работы с авто-показом в финале (Hidden & Auto-Reveal)**:
  * Chrome работает вне зоны видимости экрана (`Off-Screen`), экономя ресурсы GPU, и материализуется в финале со звуковым сигналом.

## 🛠️ Стек технологий

* **Язык:** Python 3.11+
* **Web Automation:** Selenium WebDriver, Chrome DevTools Protocol
* **GUI Library:** CustomTkinter (CTkTabview, CTkProgressBar, CTkComboBox)
* **HTTP / Data Extraction:** `requests`, `json`, `re` (Apollo State parser & JS DOM engine)
* **Image Processing:** Pillow (PIL)
* **Драйверы:** `webdriver-manager`
* **Windows API:** `ctypes.windll.user32`, `winsound`

## 📂 Структура проекта

```text
shafa-parser/
├── src/
│   ├── scraper/         # Apollo HTTP-парсер и сверхбыстрый ProfileScanner

│   ├── models.py        # Строгая типизация данных (Product, SyncItem)
│   ├── config.py        # Пути, папки и профиль Chrome
│   └── utils/           # Модули: display_utils, image_utils, logger, file_utils
├── main.py              # Двухвкладочный интерфейс GUI (CustomTkinter)
├── requirements.txt     # Актуальные зависимости проекта
└── README.md            # Документация проекта
```

## ⚙️ Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/DanilTet/shafa-parser.git
cd shafa-parser
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите приложение:
```bash
python main.py
```
